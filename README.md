# RK3568-SCH-PCB
本项目改编自Altium官方视频教程中的RK3568 AI核心板与底板组合方案。硬件设计集成了PCIe、SATA、MIPI、DP、千兆以太网、USB等多种高速接口，并搭载LPDDR4内存颗粒，采用8层PCB叠层结构。该板既可作为高速PCB设计的实战练习平台，也可用于信号完整性（SI）与电源完整性（PI）的仿真分析。
项目仍然存在许多不足之处，目前正不断完善，也非常欢迎各位指正！
